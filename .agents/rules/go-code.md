# Go code

Refines `~/.claude/rule-details/go/wrapping-errors.md` and `~/.claude/rule-details/coding-style.md`.

- **GO1** `client.gen.go` is generated by oapi-codegen and never edited by hand. To change it, change `config.yaml` or a patch in `scripts/patch-spec.sh`, then run `make generate` and commit the result.
- **GO2** A spec problem oapi-codegen cannot handle is fixed in `scripts/patch-spec.sh`, with a comment that says what is wrong upstream and what the patch does. The downloaded spec under `api/` is gitignored and never committed.
- **GO3** Hand-written Go (`gen.go`, tests) stays small. The package never logs and never prints.
- **GO4** The exported API is whatever oapi-codegen generates, with method names taken from the spec's operation IDs. A regeneration that renames or removes an exported name is a breaking change (see `releases.md`).
- **GO5** `make lint` passes with zero issues. Hand-written lines are at most 80 columns, the `.golangci.yml` limit; split calls one argument per line rather than adding `//nolint`.
- **GO6** Shell scripts in `scripts/` pass shellcheck and shfmt, which `make lint` runs.
